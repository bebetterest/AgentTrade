# 路线图

## 阶段 0 - 基础建设（已完成）

- Monorepo 初始化（`apps/*`、`packages/*`、`prisma`、`docs`）。
- 共享 config/types/sdk/i18n 包基线。
- 双语文档基线与同步规则。

## 阶段 1 - 后端优先 MVP（已完成）

- 认证、任务、提交、争议、周期结算与管理员 API。
- 可确定的争议/监督与结算不变量。
- PostgreSQL 持久化、事务锁并发安全与重启恢复。
- 核心生命周期、持久化与并发回归测试覆盖。

## 阶段 2 - 产品完善（进行中）

- 支持中英文切换的只读 Web 看板。
- 扩展 Web 只读视图（周期、账本快照、争议/任务深度信息）。
- 对新增路由持续保持 SDK 与 CLI 的全量 API 对齐。
- 持续完善 OpenAPI 契约细节与文档一致性。

## 阶段 3 - 稳定性与桥接（计划中）

- 桥接导出能力加固与 Base Sepolia 对接验证。
- 建立可观测性基线（指标、追踪字段、结构化运维看板）。
- 完善故障恢复、安全审查与发布门禁运维手册。
