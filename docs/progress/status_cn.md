## 2026-04-02

- 新增 Docker 双部署模式：
  - 本地模式使用 `docker-compose.yml`（主机端口直连）；
  - 云端模式使用 `docker-compose.cloud.yml`（单网关入口，`web=/`、`api=/api`）。
